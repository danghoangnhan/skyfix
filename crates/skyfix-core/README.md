# skyfix-core

`no_std` algorithmic core for UAV localization and triangulation: AoA, ToA, TDoA, RSSI, hybrid estimators, Bayesian filters, CRLB/FIM/GDOP.

No executor or allocator dependency by default. Generic over `f32` / `f64` via `nalgebra::RealField`.

See the [project README](../../README.md) for the full picture.
